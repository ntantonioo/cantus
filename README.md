# Cantus 

**Site de Cifras Musicais**

O **Cantus** é um site desenvolvido para organizar e disponibilizar cifras musicais, facilitando a consulta de músicas, acordes e conteúdos utilizados nos momentos de louvor e celebração da comunidade.

## 🎯 Objetivos

- Organizar cifras musicais em um único lugar.
- Facilitar a busca e a consulta de músicas.
- Disponibilizar cifras de forma simples e acessível.
- Auxiliar músicos e equipes de canto nas celebrações.

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## 🚀 Projeto

O Cantus está em desenvolvimento e busca oferecer uma plataforma simples, intuitiva e acessível para músicos e comunidades.
